# سجل الدرجات (Grades Sheet)

تطبيق ويب يعمل بدون إنترنت (PWA) لتسجيل درجات الطلاب على شعب متعددة: الأسماء مرتبة أبجدياً، الدرجات والمجموع تلقائياً، ملاحظات لكل طالب، علامات حاضر/غائب/متأخر، ونسخة احتياطية واستعادة.

الملفات الأساسية:
- `index.html` — التطبيق كله (صفحة واحدة).
- `sw.js` — يخزّن الملفات ليعمل التطبيق بدون إنترنت.
- `manifest.webmanifest` والأيقونات `icon-*.png` — لإضافته إلى الشاشة الرئيسية.

## التثبيت على الآيباد
1. انشر الملفات على استضافة ثابتة بـ https (Netlify أو GitHub Pages).
2. افتح الرابط في Safari والإنترنت شغال حتى تُحمَّل الصفحة.
3. مشاركة ← «إضافة إلى الشاشة الرئيسية»، ثم افتحه من الأيقونة.

## التحديث
عند أي تعديل على `index.html` غيّر اسم الإصدار في أول سطر من `sw.js` (مثل `grades-v14`) حتى يصل التحديث إلى الأجهزة.

## الخصوصية
البيانات (الأسماء والدرجات والملاحظات) تُحفظ على الجهاز نفسه فقط ولا تُرفع إلى أي مكان. المستودع يحوي الكود فقط، ولا يحوي أي بيانات طلاب.
